## 目标

验证同一份 Markdown 可以在 Obsidian 编辑，并通过 Quartz 生成网页。

## 操作流程

1. 在 Obsidian 打开项目的 `content` 文件夹。
2. 编辑任意示例笔记，保存。
3. 在项目根目录运行 `npm run preview` 查看本地变化。
4. 运行 `npm run publish`，由 GitHub Actions 构建并发布。

## 验收项目

- 首页能打开课程目录。
- 章节笔记中的双链可以跳转。
- 搜索能找到“验收标准”。
- 切换深色主题后文字仍然清晰。
