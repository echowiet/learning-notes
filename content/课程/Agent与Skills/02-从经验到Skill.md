## 我的理解

制作 Skill 的起点是一项重复工作：它有明确的输入、处理步骤、输出和验收标准。

## 以数据核对为例

| 项目 | 示例 |
| --- | --- |
| 输入 | 两份待核对的 CSV 和关联字段 |
| 步骤 | 检查字段、统一格式、关联记录、找出差异 |
| 输出 | 差异明细与统计说明 |
| 验收 | 差异可追溯，总数能对上 |
